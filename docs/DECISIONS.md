# قرارات التدقيق — DECISIONS

> سجل مختصر للقرارات التي أثّرت على التدقيق. لا توجد تغييرات في أوزان التشخيص أو
> بيانات الأدوية أو الجرعات في هذا العمل.

## 2026-11-11 — لا تغيير في المنطق السريري أثناء التدقيق

**القرار:** لم أغيّر أوزان الحالات، حدود الثقة، بيانات الأدوية/الجرعات، قواعد
الفرز، أو حساب EWS.

**السبب:** ظهرت ثلاث نقاط تحتاج قراراً طبياً:

1. `chest_pain` منفرداً يبقى `routine` رغم أن تعليق `assessTriage` يقول إن أي علامة
   إنذارية ترفع إلى «عاجل» على الأقل.
2. ضغط انقباضي 180–219 لا يحصل على نقاط EWS رغم تصنيفه «مرتفع جداً» (219 → EWS 0).
3. بعض النتائج تبدو غير منطقية سريرياً: COPD قبل CAP، وهلع بفرز طارئ، ونقص سكر
   بتخليط بفرز شبه عاجل فقط.

أي تعديل هنا يغيّر سلوكاً سريرياً/فرزاً، ويحتاج اعتماد الطبيبة. وُثّقت الحالات في
`docs/TEST_CASES.md` و`docs/FEATURES_CHECKLIST.md` كعيوب معروفة، مع اختبارات انحدار
تصف السلوك الحالي (الحالتان 27 و28) ولا تدّعي صحته.

## 2026-11-11 — البيانات الطبية تبقى عربية فقط

**القرار:** واجهة AR/FR/EN، لكن أسماء الحالات والأعراض والتخصصات والتوصيات
والفحوصات والإجراءات والتحذيرات تبقى عربية. أُزيلت خرائط الترجمة الفرنسية السابقة
للمصطلحات الطبية لأنها غير مُراجعة.

**السبب:** طلب صريح بعدم ترجمة المحتوى الطبي غير المعتمد أو تقديمه كمراجَع.

## 2026-11-11 — بيانات الأدوية تبقى في حزمة GitHub Pages

**القرار:** لا حذف لبيانات الأدوية من الكود ولا نقل المحرك إلى خادم خارجي. تبقى
البيانات في الحزمة الثابتة، مع استمرار `actions.medications = []` في API وإخفاء
القسم في الواجهة.

**السبب:** قرار المالك الصريح بالاحتفاظ بالبيانات للمراجعة والتحرير والاعتماد لاحقاً.
**الحد المعروف:** الحزمة العامة تحتوي البيانات الأصلية، ولا يصح وصفها بأنها سرية.

## 2026-11-11 — تصحيحات غير سريرية

- README: «فرز ثلاثي المستوى» → «فرز رباعي المستويات» (الكود يعرض أربعة).
- README: وصف الأدوية → توضيح أنها محجوبة حتى المراجعة.
- PLATFORM_AUDIT: «25 عرضاً» → **58 عرضاً** الفعلي.
- إضافة توثيق المصادر والحالات والخصائص دون أي ادعاء باعتماد طبي.
